Linux là một hệ điều hành linh hoạt, thường có rất nhiều công cụ khác nhau mà chúng ta có thể sử dụng để thực hiện file transfer.
## Download Operations
Chúng ta có quyền truy cập vào máy `NIX04` và cần tải một file từ máy `Pwnbox`. Hãy xem chúng ta có thể thực hiện việc này bằng nhiều phương pháp file download khác nhau như thế nào.
![[Linux File Transfer Methods.png]]

## Base64 Encoding / Decoding
Tuỳ thuộc vào kích thước file mà chúng ta muốn truyền, chúng ta có thể sử dụng một phương pháp không yêu cầu giao tiếp mạng. Nếu có quyền truy cập vào terminal, chúng ta có thể encode một file thành chuỗi Base64, sao chép nội dung của nó vào terminal và thực hiện thao tác ngược lại.
